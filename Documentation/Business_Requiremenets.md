#  Автоматизована ШІ-система утримання клієнтів стрімінгової платформи (Smart Movie Retention System).

## **1\. Бізнес-проблема (Business Problem)**

Стрімінгові платформи стикаються з високим рівнем відтоку клієнтів (Customer Churn) через феномен "паралічу вибору" — користувачам важко знайти релевантний контент серед тисяч фільмів. Існуючий процес email-маркетингу є неефективним: розсилки створюються вручну, містять однакові базові рекомендації для всіх (наприклад, "Топ-10 новинок тижня") і мають низький відсоток відкриттів (Open Rate) та переходів (Click-Through Rate). Компанія втрачає гроші на залучення нових клієнтів замість того, щоб утримувати існуючих.

## **2\. Бізнес-цілі (Business Objectives)**

Впровадження даної системи має на меті досягнення наступних високорівневих цілей:

* **Збільшення залученості користувачів (Retention):** Повернути неактивних користувачів на платформу шляхом надання високоточних рекомендацій контенту.  
* **Автоматизація маркетингу (Operational Efficiency):** Повністю усунути ручну працю при створенні та розсилці email-кампаній, заощадивши час маркетингового відділу.  
* **Гіперперсоналізація комунікації:** Підвищити конверсію маркетингових листів за рахунок використання генеративного штучного інтелекту, який створює унікальний текст для кожного користувача на основі його індивідуальних смаків.

## **3\. Образ рішення (Vision of the Solution)**

Проект являє собою автономний мікросервіс без графічного інтерфейсу. Система автоматично, за заданим розкладом, аналізує історію переглядів користувачів (на базі даних [MovieLens](https://www.kaggle.com/datasets/grouplens/movielens-20m-dataset?select=tag.csv)). Використовуючи алгоритми машинного навчання (Collaborative Filtering), вона прогнозує 3 найбільш релевантні фільми для кожного клієнта. Далі система передає ці дані генеративному ШІ (LLM), який пише унікальний, персоналізований мотиваційний лист. Завершальним етапом є автоматична відправка цього листа на електронну пошту клієнта.

## **4\. Межі проекту (Project Scope)**

Щоб уникнути "розповзання" меж проекту (Scope Creep), чітко визначено, що входить, а що не входить у поточну реалізацію.

**Що ВХОДИТЬ у межі проекту:**

* Розробка та навчання рекомендаційної ML-моделі на датасеті MovieLens 20M.  
* Створення REST API (FastAPI) для отримання прогнозів від моделі.  
* Налаштування автоматизованого процесу (Pipeline) у системі n8n.  
* Інтеграція з API генеративного ШІ (наприклад, OpenAI або Google Gemini) для створення текстів листів.  
* Налаштування автоматичної відправки електронних листів кінцевим користувачам.

**5\. Кількісні критерії успіху (Success Criteria)**

Проект вважається успішним, якщо:

1. Пайплайн в n8n працює автономно і успішно завершує повний цикл (від запиту до відправки листа) без помилок.  
2. Згенеровані тексти листів є логічними, не містять помилок (вигаданих фільмів) і чітко аргументують вибір рекомендацій на основі минулої історії користувача.
